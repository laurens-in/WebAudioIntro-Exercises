# Final Assignment

First open your terminal and run `npm install`. Make sure you are located inside this folder in your terminal.

Then you can run the dev server with `npm run dev`. And had to the address posted in your terminal.

You can now take a look at `main.js`. There is already a button with an event listener. Make it so that when this button is clicked, a small composition starts playing. Can be one sound, can be multiple sounds, doesn't really matter. I setup the button for you but you still have to create the AudioContext etc.

To see your `console.log` open the dev console with either `Ctrl + Shift + I` or `F12`.
