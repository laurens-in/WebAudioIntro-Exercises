# Sample Example

First open your terminal and run `npm install`. Make sure you are located inside this folder in your terminal.

Then you can run the dev server with `npm run dev`. And had to the address posted in your terminal.

You can now take a look at `main.js` and see how this example works.

To see your `console.log` open the dev console with either `Ctrl + Shift + I` or `F12`.
